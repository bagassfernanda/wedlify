# Incident Report INC-001

| Field | Isi |
|-------|-----|
| Incident ID | INC-001 |
| Judul | Panel Rincian Harga menampilkan "Pilih paket untuk melihat rincian harga." padahal paket sudah dipilih |
| Test case terkait | TC-EP-04 (teramati saat eksekusi). Gejala yang sama muncul pada setiap kasus yang memilih paket. |
| Test basis | REQ-015 dan BR-33: sistem menghitung dan menampilkan total pesanan dari paket yang dipilih. Fitur F05 Perhitungan Harga dan Kode Promo. |

| Pelapor | (isi nama) |

## Ringkasan

Setelah paket dipilih pada form Buat Pesanan, panel Rincian Harga tetap menampilkan petunjuk "Pilih paket untuk melihat rincian harga." sampai hasil hitung harga diterima dari server. Selama jeda itu, isi panel bertentangan dengan pilihan paket pada form. Pada server lokal jedanya sekitar 0,8 detik, dan makin lama pada koneksi yang lambat.

## Prasyarat

1. Aplikasi berjalan dan User sudah login.
2. Halaman Buat Pesanan (`#/orders/new`) terbuka dan field Paket belum dipilih.

## Langkah reproduksi

1. Buka Chrome DevTools, tab Network, lalu ubah throttling menjadi "Slow 3G" supaya jedanya mudah diamati.
2. Pada form Buat Pesanan, pilih Paket "Standard (Rp 300.000)".
3. Amati panel Rincian Harga di sisi kanan segera setelah paket dipilih.

## Hasil yang diharapkan

Begitu paket dipilih, panel Rincian Harga tidak lagi meminta User memilih paket. Panel menampilkan rincian harga paket itu, atau keterangan bahwa harga sedang dihitung.

## Hasil aktual

Panel tetap menampilkan "Pilih paket untuk melihat rincian harga." walaupun field Paket sudah berisi "Standard (Rp 300.000)". Pesan itu baru berganti menjadi rincian harga (Total Rp 300.000) setelah respons server diterima.

Pengukuran saat reproduksi:

| Kondisi | Lama pesan keliru tampil |
|---------|--------------------------|
| Server lokal tanpa throttling | sekitar 0,8 detik |
| Respons hitung harga ditunda 5 detik | sekitar 5 detik |

## Alasan severity

Rendah. Total yang akhirnya ditampilkan dan yang disimpan tetap benar, dan User tetap dapat membuat pesanan. Dampaknya terbatas pada petunjuk yang menyesatkan untuk sementara, yang dapat membuat User mengira pilihannya belum terbaca, terutama pada koneksi lambat.

## Catatan untuk perbaikan

Dugaan lokasi: `src/pages/OrderFormPage.tsx`. Pesan panel hanya diperbarui saat paket kosong dan saat respons hitung harga tiba, sehingga pesan lama tetap tampil selama menunggu. Setelah diperbaiki, jalankan ulang langkah reproduksi di atas (retest) dan TC-BVA-09 serta TC-EP-01 sampai TC-EP-03 (regression).
